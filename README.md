- Isaac Lab: https://github.com/isaac-sim/IsaacLab
- UrbanSim: https://github.com/metadriverse/urban-sim
- This repo stays close to upstream and includes only **minor** changes and utilities needed for rendering and physics.
- For the full framework, documentation, and official releases, please refer to the upstream repositories.

## Notes

This is **not** the official Isaac Lab repository. If you’re looking for more installation instructions or general Isaac Lab usage, please use the upstream docs.
